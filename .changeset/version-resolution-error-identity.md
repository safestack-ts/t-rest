`VersionResolutionError` is recognized across module copies via `instanceof` and the new `VersionResolutionError.isVersionResolutionError(error)`. Export the `RequestVersion` type of versioned route requests. Typed middlewares accept handlers returning `unknown`, so plain express 5 request handlers can be passed to `.middleware()` and `.use()`.
